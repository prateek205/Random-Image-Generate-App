# 🖼️ Random Image Generator App

A simple and interactive **Random Image Generator** built using **HTML, CSS, and Vanilla JavaScript**.  
This application fetches and displays random images dynamically with a single button click, making it a great beginner-friendly JavaScript project.


## 🚀 Features

- 🎲 Generates a new random image on every click  
- ⚡ Fast and lightweight (no frameworks or libraries)  
- 🧠 Uses pure JavaScript logic  
- 📱 Fully responsive design  
- 🎨 Clean and minimal UI  
- 🔁 Refresh images without reloading the page  


## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript (Vanilla JS)** – Logic & DOM manipulation

## ⚙️ How It Works

- A button triggers a JavaScript function
- The function generates a random image URL
- The image source is updated dynamically using DOM manipulation
- A new image loads instantly without refreshing the page


## 🧪 How to Run the Project

1. Clone or download the repository
2. Open the project folder
3. Double-click `index.html`  
   **OR**
4. Open it using Live Server in VS Code
